# Terminology note (draft)

| Term | Meaning | Standard |
|---|---|---|
| Plain language | Clear communication for a broad audience | ISO 24495-1 |
| Easy-to-Read / Easy Language | Stricter rules for readers with significant reading or comprehension difficulties | Inclusion Europe, *Information for all*; German: DIN SPEC 33429 |

The brief says "plain language" but cites DIN SPEC 33429, which is an Easy Language standard.
Working term: "Easy Language", pending supervisor decision (memo question 1).

Consequence of the choice:
- Easy-to-Read: stricter word lists and grammar rules, larger expected simplification gap.
- Plain language: looser rules, smaller gap, fewer lookup replacements.
